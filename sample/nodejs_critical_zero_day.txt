A critical remote code execution vulnerability has been discovered in Node.js versions 20.x and 22.x that allows unauthenticated remote attackers to execute arbitrary code through malicious HTTP headers.

AFFECTED VERSIONS:
- Node.js 20.0.0 through 20.11.0
- Node.js 22.0.0 through 22.1.0
- ALL platforms (Linux, macOS, Windows)

IMMEDIATE ACTION REQUIRED:
1. **UPGRADE IMMEDIATELY** to Node.js 20.11.1 or 22.1.1
2. Restart all Node.js services
3. Check access logs for exploitation attempts since January 28, 2026
4. Review npm packages for potential compromise

TECHNICAL DETAILS:
- Attack vector: Malformed HTTP headers in Express/Fastify applications
- No authentication required
- Exploitable remotely over network
- Privilege escalation to root/SYSTEM possible
- Wormable - can spread automatically

INDICATORS OF COMPROMISE:
- Unusual CPU spikes on Node.js processes
- New files in /tmp/ or C:\Windows\Temp\
- Outbound connections to unknown IPs on ports 4444, 5555
- Modified package.json or node_modules
